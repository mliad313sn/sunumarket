# Guide livreur (Moussa)

1. Ouvrez l'app Livreur → connectez-vous. Les courses disponibles apparaissent : repère, course en FCFA, badge 💵 si paiement à la livraison (COD).
2. **Accepter** : premier arrivé, premier servi. Boutons : Colis récupéré → En route → Arrivé.
3. **Pas de réseau ?** Continuez — vos statuts sont enregistrés et synchronisés automatiquement.
4. **À la remise** : demandez le code de réception à 4 chiffres du client et saisissez-le. Sans code correct, pas de livraison confirmée.
5. **COD** : vérifiez les billets (filigrane, toucher). Votre plafond d'encaissement dépend de votre vérification (pièce + véhicule). Remettez via **PI-SPI (instantané)** ou dépôt agent.
6. **Problème ?** « Signaler un problème » — le vendeur et le support prennent le relais.
