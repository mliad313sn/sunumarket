# Guide vendeur (Awa)

1. **Créer votre boutique** : SunuMarket → « Se connecter » → votre numéro → code SMS à 6 chiffres. Puis « Créer ma boutique » : nom, ville — c'est tout (moins de 10 min).
2. **Ajouter un produit** : photo, titre, prix en FCFA, stock. Il est en ligne immédiatement ; partagez le lien sur TikTok/WhatsApp.
3. **Vos moyens de paiement** : par défaut tous ceux de votre pays (Wave d'abord au Sénégal). Vous pouvez en retirer, jamais en ajouter hors matrice.
4. **RÈGLE D'OR** : ne livrez JAMAIS sur la base d'un SMS ou d'une capture d'écran. Attendez le statut **PAYÉ** dans l'app — c'est la seule preuve (les faux SMS de paiement sont fréquents).
5. **Livraison** : commande payée → « Demander une livraison » : vous-même, un livreur (diffusion automatique), ou le partenaire. Le buyer a un code de réception à 4 chiffres — le livreur doit le saisir.
6. **Votre argent** : Solde → « Retirer » → instantané via PI-SPI vers n'importe quel portefeuille. Plafonds selon votre palier de vérification (ajoutez votre pièce d'identité pour les augmenter). PIN de retrait recommandé.
7. **Nouveau téléphone ?** Reconnexion + 24 h de délai avant retrait (protection anti-fraude).
