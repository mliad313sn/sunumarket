# Guide admin (Fatou)

1. Console → 8 onglets. **dashboard** : volumes + files ouvertes (litiges, fraude, réconciliation).
2. **search** : n'importe quel numéro → comptes + commandes invité.
3. **kyc** : file des demandes de palier — approuver/rejeter (le palier s'applique immédiatement).
4. **fraud** : anomalies (rafales d'échecs, multi-comptes, nouveaux appareils, références forgées) — clear/action.
5. **reconciliation** : écarts de règlement avec ancienneté — objectif purge <72 h (voir SOP).
6. **disputes** : rembourser (rail d'origine + gel levé) ou rejeter.
7. **config** : matrice par pays, bascule de route (effet immédiat, audité), toggle MANUAL_TRANSFER, rechargement des packs.
8. Toute action de config est journalisée (audit).
